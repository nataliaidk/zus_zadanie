# Frontend — wireframe (Prompt 3–4)

Next.js App Router, TypeScript, Tailwind tylko do siatki/`border`/`p-4`/`gap-4`/`focus-visible`.

Logika w `hooks/useGuidedChat.ts` i `hooks/useParentPlan.ts`.

```bash
cd frontend
npm install
npm run dev
```

Backend musi działać na `:8000` (`next.config.ts` proxy `/api` → FastAPI).
